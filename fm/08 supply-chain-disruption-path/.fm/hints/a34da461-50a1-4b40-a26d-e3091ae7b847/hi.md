# 위험 매출 계산식을 고교 수학으로 읽기

> 고등학교 수학(일차함수, 부등식, 적분의 뜻)만으로 이 식을 완전히 이해할 수 있다. 새로 필요한 개념은 하나뿐이다 — **"비율(rate)에 시간을 곱하면 총량이 된다"**.

우리가 이해할 식은 두 개다.

$$\text{revenue\_at\_risk} = \frac{\text{annualRevenue}}{365} \times \text{daysOfSupplyOnHand}$$

$$\text{urgency} = 100 - 10 \times \text{daysOfSupplyOnHand}$$

기호를 줄여 쓰자. 연 매출을 $R$, 재고로 버틸 일수를 $D$ 라 하면

$$V(D) = \frac{R}{365}D, \qquad U(D) = 100 - 10D$$

---

## 1단계: 연 매출을 일 매출로 — 왜 나누기 365인가

### 비례식으로 보기

"1년에 $R$원을 번다"를 "하루에 얼마?"로 바꾸는 것은 초등학교 비례식이다.

$$365\ \text{일} : R\ \text{원} \;=\; 1\ \text{일} : x\ \text{원}$$

$$365x = R \quad\Longrightarrow\quad x = \frac{R}{365}$$

이 $x$ 를 **일 매출**(daily revenue) 이라 부르고 $r$ 로 쓰자.

$$r = \frac{R}{365}$$

예를 들어 $R = 50{,}000{,}000$ 달러(5천만 달러)라면

$$r = \frac{50{,}000{,}000}{365} \approx 136{,}986 \ \text{달러/일}$$

### 왜 "일차함수"인가

여기서 중요한 것은 **일수와 매출의 관계가 원점을 지나는 일차함수(정비례)** 라는 점이다. $t$ 일 동안 쌓인 매출을 $f(t)$ 라 하면

$$f(t) = r\,t$$

- $f(0) = 0$ : 0일 동안은 0원. → **원점을 지난다**
- $f(365) = r \cdot 365 = R$ : 365일이면 연 매출. → 정의와 일치
- 기울기 $= r = \dfrac{R}{365}$ : 하루 지날 때마다 늘어나는 매출

즉 $\dfrac{R}{365}$ 라는 나눗셈은 **"매출 누적 그래프의 기울기를 구하는 일"** 이다. 기울기 공식 그 자체다.

$$\text{기울기} = \frac{y\text{의 변화량}}{x\text{의 변화량}} = \frac{R - 0}{365 - 0} = \frac{R}{365}$$

이 정비례 가정은 **"매출이 1년 내내 고르게 발생한다"** 는 뜻이다. 실제로는 연말에 몰리거나 신제품 출시 직후에 몰릴 수 있는데, 그러면 $f(t)$ 는 직선이 아니라 굽은 곡선이 된다. 우리 식은 그 곡선을 **직선으로 근사**한 것이다.

## 2단계: 왜 $D$ 를 곱하는가 — 면적과 적분

### 단위로 확인하기 (물리에서 배운 차원 검산)

물리에서 $\text{거리} = \text{속력} \times \text{시간}$ 이었던 것과 똑같은 구조다.

| 물리 | 공급망 |
|---|---|
| 속력 $v$ [m/s] | 일 매출 $r$ [달러/일] |
| 시간 $t$ [s] | 버퍼 일수 $D$ [일] |
| 거리 $s = vt$ [m] | 위험 매출 $V = rD$ [달러] |

$$\left[\frac{\text{달러}}{\text{일}}\right] \times [\text{일}] = [\text{달러}] \quad \checkmark$$

단위가 맞는다는 것만 확인해도 식의 형태가 옳다는 강한 증거다. 만약 실수로 $R \times D$ 로 썼다면 단위가 [달러·일/년]이 되어 말이 안 된다.

### 면적으로 보기

가로축을 시간 $t$(일), 세로축을 **매출률** $r$(달러/일)로 잡으면, $r$ 은 상수이므로 그래프는 **수평선**이다.

```
매출률 r (달러/일)
  │
r ├──────────────┐
  │░░░░░░░░░░░░░░│   ← 이 직사각형의 면적 = revenue_at_risk
  │░░░░ r × D ░░░│
  │░░░░░░░░░░░░░░│
  └──────────────┴──────→ 시간 t (일)
  0              D
```

직사각형의 면적 $=$ 가로 $\times$ 세로 $= D \times r$. 이것이 바로 $V(D)$ 다.

### 적분으로 보기 (미적분 연결)

"변화율 그래프 아래 면적 = 총 변화량"은 미적분의 핵심 정리다. 매출률 $r(t)$ 가 시간에 따라 변할 수 있는 일반적인 경우,

$$V = \int_0^{D} r(t)\,dt$$

우리 모델은 $r(t) = r$ (상수)라고 가정했으므로

$$V = \int_0^{D} r\,dt = r\big[t\big]_0^{D} = rD$$

**우리 식은 "상수 함수의 정적분"이라는 가장 단순한 적분이다.** 만약 매출이 계절에 따라 $r(t) = r_0(1 + 0.3\sin\frac{2\pi t}{365})$ 처럼 변한다면 적분값이 달라지고, 그때는 이 단순 곱셈이 오차를 낸다.

### 그러면 $D$ 는 무슨 기간인가

$D = \text{daysOfSupplyOnHand}$ 는 **"지금 창고에 있는 재고로 몇 일을 더 생산할 수 있는가"** 다. 공급이 끊긴 순간부터 $D$ 일 뒤에 생산이 멈춘다.

- $D$ 일은 **아직 시간이 있는 구간** = 대응할 수 있는 창(decision window)
- 그 창 동안 회사 파이프라인을 흐르는 매출이 $rD$
- 이것이 "이번 중단 사이클에서 직접 걸려 있는 금액"의 1차 근사

$D$ 가 클수록 노출 금액 $V$ 도 커진다 — 창이 넓으면 그 안에서 흐르는 매출도 많으니 당연하다.

## 3단계: urgency는 기울기 $-10$ 의 일차함수

$$U(D) = 100 - 10D$$

이것은 완전히 표준적인 $y = ax + b$ 꼴이다.

| 항 | 값 | 뜻 |
|---|---|---|
| $y$ 절편 $b$ | $100$ | $D = 0$, 즉 **재고가 이미 0일** → 시급도 최대 100점 |
| 기울기 $a$ | $-10$ | 재고 여유가 **하루 늘 때마다 시급도 10점 하락** |
| $x$ 절편 | $D = 10$ | $U = 0$ 이 되는 지점. 10일 버티면 급하지 않음 |

그래프는 $(0, 100)$ 에서 시작해 $(10, 0)$ 으로 내려가는 **오른쪽으로 하강하는 직선**이다.

```
urgency U
100 ●
    │╲
 70 ┼──╲─ ─ ─ ─ ─ ─ ─ ─ ─  (임계선)
    │ ┆  ╲
    │ ┆     ╲
  0 ┼─┆────────●──────→ D (일)
    0 3        10
      ↑
   임계 교점
```

**기울기가 음수라는 사실이 핵심이다.** $V(D)$ 는 기울기가 양수($+r$)이고 $U(D)$ 는 음수($-10$) — 두 지표는 **서로 반대 방향**으로 움직인다.

| $D$ | $V(D)$ 위험 금액 | $U(D)$ 시급도 |
|---|---|---|
| 작다 (재고 부족) | 작다 | **크다** |
| 크다 (재고 여유) | **크다** | 작다 |

$D = 10$ 을 넘으면 $U$ 가 음수가 된다. 점수는 음수일 수 없으니 실제 구현에서는

$$U(D) = \max(0,\ 100 - 10D)$$

로 **아래를 0에서 자른다**. 이렇게 자른 함수는 $D = 10$ 에서 꺾이므로 미분 가능하지 않은 점이 하나 생긴다(절댓값 함수의 꼭짓점과 같은 상황).

## 4단계: `urgency > 70` 은 사실 부등식 문제

문서의 필터 조건은 이렇게 쓰여 있다.

$$\text{critical\_product\_lines} = \text{WHERE urgency} > 70$$

이 조건이 실제로 무엇을 뜻하는지 **부등식을 풀어서** 확인하자.

$$100 - 10D > 70$$

양변에서 $100$ 을 빼면

$$-10D > -30$$

양변을 $-10$ 으로 나눈다. **음수로 나누면 부등호 방향이 뒤집힌다** (고1에서 배운 규칙).

$$D < 3$$

### 결론

$$\boxed{\text{urgency} > 70 \iff \text{daysOfSupplyOnHand} < 3}$$

두 조건은 **완전히 동치**다. 즉 "시급도 70점 초과"라는 점수 기준은 겉보기에 임의로 정한 숫자 같지만, 실제로는 **"재고가 3일도 안 남았다"** 는 운영 기준을 0~100 점수로 옮겨 적은 것에 불과하다.

### 임계값을 바꾸면?

일반적으로 임계값 $\tau$ 에 대해

$$100 - 10D > \tau \iff D < \frac{100 - \tau}{10}$$

| 임계 $\tau$ | 대응하는 조건 |
|---|---|
| 90 | $D < 1$ (1일 미만) |
| 80 | $D < 2$ |
| **70** | **$D < 3$** ← 문서의 선택 |
| 50 | $D < 5$ |
| 0 | $D < 10$ |

임계값 하나가 곧 "며칠"이라는 운영 기준과 1:1 대응한다. 기울기가 $-10$ 이라는 것 덕분에 이 변환이 깔끔하게 떨어진다.

### 자동화 트리거는 연립부등식

문서의 Phase 5는 두 조건을 AND로 묶는다.

$$V > 50{,}000{,}000 \quad \textbf{그리고} \quad D < 5$$

$V = \dfrac{R}{365}D$ 이므로 첫 조건은 $R$ 과 $D$ 에 관한 부등식이다.

$$\frac{R}{365}D > 5\times 10^{7} \iff RD > 1.825 \times 10^{10}$$

$RD > \text{const}$ 는 $R$–$D$ 평면에서 **반비례 곡선(쌍곡선) 위쪽 영역**이다. 여기에 $D < 5$ 라는 세로 직선 왼쪽 영역을 교집합으로 취한다.

```
R (연 매출)
 │      ┆
 │▓▓▓▓▓▓┆        ← RD > c 이면서 D < 5 인 영역(자동 실행)
 │ ▓▓▓▓▓┆╲
 │   ▓▓▓┆   ╲___  RD = c (쌍곡선)
 │      ┆
 └──────┴────────→ D (일)
        5
```

**두 지표가 반대 방향으로 움직이기 때문에 이 교집합은 저절로 좁아진다.** 금액만 크고 시간 여유가 있는 건은 걸리지 않고, 급하지만 금액이 작은 건도 걸리지 않는다. "알람이 너무 많아 아무도 안 본다"는 문제를 수학적 구조로 막은 것이다.

## 5단계: 계산해 보기

### 예제 1 — 단일 제품 라인

Gaming Laptop 2024: $R = \$50\text{M}$, 병목 부품 GPU Module의 $D = 3$ 일.

$$r = \frac{50{,}000{,}000}{365} \approx 136{,}986\ \text{달러/일}$$
$$V = 136{,}986 \times 3 \approx 410{,}959\ \text{달러} \approx \$0.41\text{M}$$
$$U = 100 - 10\times 3 = 70$$

$U = 70$ 은 $70$ **초과가 아니므로** `urgency > 70` 필터에 **걸리지 않는다**. 부등식이 등호를 포함하지 않는다는 점($D<3$, 즉 3일은 제외)에 주의해야 한다. 경계값 처리는 늘 함정이다.

### 예제 2 — 두 라인 합산과 분배법칙

Workstation Pro: $R = \$30\text{M}$, 같은 부품이므로 $D = 3$.

$$V_{\text{total}} = \frac{50\text{M}}{365}\times 3 + \frac{30\text{M}}{365}\times 3$$

$D$ 가 같으므로 **분배법칙**으로 묶을 수 있다.

$$= \frac{3}{365}\big(50\text{M} + 30\text{M}\big) = \frac{3}{365}\times 80\text{M} \approx 657{,}534\ \text{달러} \approx \$0.66\text{M}$$

일반적으로 여러 라인의 $D$ 가 모두 같다면

$$V_{\text{total}} = \frac{D}{365}\sum_i R_i$$

즉 **"연 매출 총합의 $\frac{D}{365}$ 배"** 라는 간단한 형태가 된다. $D = 3$ 이면 $\frac{3}{365} \approx 0.82\%$ — 연 매출 합의 1퍼센트도 안 되는 금액이다.

### 주의: 문서의 $80M과 정의가 다르다

자산 문서의 캐스케이드 예시는 `revenueAtRisk = $80M` 이라고 적어 놓았다. 이는 $50\text{M} + 30\text{M}$, 즉 **연 매출을 그냥 더한 값**이다. 방금 Phase 3 식으로 계산한 $0.66M과 약 **122배**($= 365/3$) 차이 난다.

$$\frac{80\text{M}}{0.66\text{M}} = \frac{80\text{M}}{\frac{3}{365}\times 80\text{M}} = \frac{365}{3} \approx 121.7$$

이 배수가 정확히 $\frac{365}{3}$ 인 것은 우연이 아니다. 두 값이 **같은 분자에 $\frac{D}{365}$ 만 다르게 붙은 관계**이기 때문이다. 두 숫자는 서로 다른 질문에 답한다.

- $\$80\text{M}$ — "얼마나 **큰 사업**이 위태로운가" (규모, 연 단위 스톡)
- $\$0.66\text{M}$ — "버퍼 기간에 **실제로 흐르는** 매출은 얼마인가" (유량 × 시간)

어느 쪽이 옳다기보다, **어떤 정의를 쓰는지 명시하지 않으면 두 자릿수 배수의 오차가 발생한다**는 것이 교훈이다.

## 정리: 세 가지 수학적 관찰

1. **$\dfrac{R}{365}$ 는 기울기다.** 매출 누적 그래프 $f(t) = rt$ 는 원점을 지나는 일차함수이고, $\frac{R}{365}$ 는 그 기울기 $\frac{\Delta y}{\Delta x} = \frac{R-0}{365-0}$ 이다. 이는 "매출이 1년간 균등"이라는 직선 근사를 뜻한다.

2. **$\times D$ 는 면적(적분)이다.** $V = \int_0^D r\,dt = rD$ — 높이 $r$, 너비 $D$ 인 직사각형의 면적. 상수함수 적분이라는 가장 단순한 경우다. 단위 $\frac{\text{달러}}{\text{일}}\times\text{일} = \text{달러}$ 로 검산된다.

3. **`urgency > 70` 은 일차부등식이다.** $100 - 10D > 70 \Rightarrow -10D > -30 \Rightarrow D < 3$ (음수로 나눠 부등호 역전). 점수 임계값은 운영 기준(일수)의 재표현일 뿐이며, 기울기 $-10$ 이 $V$ 의 양의 기울기와 반대 방향이라는 점이 알람 과다를 막는 구조를 만든다.
